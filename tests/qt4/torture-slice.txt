# Torture slice: the first conformance target (Phase 0 task 0.9).
#
# Test cases from the W3C QT4 test suite (qt4cg/qt4tests at the commit pinned
# in tools/fetch-test-suites.sh, decision D13) that stress the XDM value model:
# function items, maps, arrays, JSON, node identity and order across several
# documents, casting, ranges and errors. A base of arithmetic, string, path and
# comparison tests makes the slice a coherent first target.
#
# Every test is applicable to XP40 (most to both XP40 and XQ40), needs no
# schema awareness, no collation other than the codepoint collation, no
# modules and no serialization feature. The only feature dependency allowed is
# higherOrderFunctions.
#
# try/catch: every TryCatchExpr test in the suite is XQ40-only, so errors are
# covered here through fn:error, dynamic and type errors, and `error`
# assertions.
#
# Format: <test-set-name> <test-case-name>  # reason
# Check:  python3 tools/check-test-list.py tests/qt4/torture-slice.txt

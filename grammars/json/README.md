# JSON grammar

A strict tree-sitter grammar for JSON texts (RFC 8259), used by sxml's JSON
functions (`fn:parse-json`, `fn:json-to-xml`; F&O 4.0, section 17.4;
docs/DECISIONS.md, D12 and the JSON record). Original work of the sxml
project (MIT, see the repository LICENSE); no code of tree-sitter-json was
copied.

| File | Origin |
| --- | --- |
| `grammar.js` | Hand-written after RFC 8259, sections 2 to 7. |
| `src/parser.c`, `src/grammar.json`, `src/node-types.json`, `src/tree_sitter/` | Generated by `tools/generate-grammars.sh json`; committed. |
| `test/corpus/*.txt` | tree-sitter corpus tests. |
| `tree-sitter.json` | Grammar metadata for the CLI. |

Regenerate and test (needs `npm ci --prefix tools`):

```sh
tools/generate-grammars.sh json
cd grammars/json && ../../tools/node_modules/.bin/tree-sitter test
```

## Contract with the tree walk (`src/json.c`)

The input is UTF-8 without a byte order mark and without U+0000 (the walk
removes the mark and refuses U+0000, which tree-sitter would read as the
end of the input). **Any `ERROR` or `MISSING` node means the text is not
JSON** (err:FOJS0001). No extension is accepted.

| Node (fields) | RFC 8259 | Notes |
| --- | --- | --- |
| `document` (`value`) | 2 | One value; whitespace around it is extra. |
| `object` (`member`*) | 4 | |
| `member` (`key`, `value`) | 4 | `key` is a `string`. |
| `array` (`member`*) | 5 | |
| `number` | 6 | One token; its text is the lexical form. |
| `string` | 7 | Children `unescaped_text` and `escape_sequence` in order; no children for `""`. |
| `escape_sequence` | 7 | `\"` `\\` `\/` `\b` `\f` `\n` `\r` `\t` or `\u` and four hex digits. Surrogate pairing is the walk's. |
| `true`, `false`, `null` | 3 | |
